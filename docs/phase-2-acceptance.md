# Phase 2 Acceptance Record

**Status:** Passed by Theo's final human acceptance evaluation on 2026-08-21.

Phase 2 demonstrated that the Trading Mentor is a reliable private,
source-grounded persistent chat foundation over the real Jacob Speculates corpus.
This record deliberately excludes private conversation transcripts, local
runtime data, and API secrets.

## Human-accepted evidence

- Persistent conversation restoration, switching, reload persistence, and
  local-only permanent conversation deletion.
- Historical Markdown, evidence, diagnostics, and the settings that produced
  each response.
- Auto, Normal, Deep, and Exhaustive research depth; provenance separation;
  exhaustive source research; and source-grounded correction behavior.
- Native long-thread compaction with continued usable conversation, plus
  visible/recoverable stream failures.
- Native citations for substantive Direct source teaching, source-verifiable
  exact timestamps, and truthful distinction between cited sources and
  retrieved File Search passages.
- Readable evidence timestamps and usable table scrolling/wrapping behavior.

## Preserved decisions for future phases

- **Model routing recommendation only:** GPT-5.6 Terra is promising for Normal
  mentor questions; GPT-5.6 Sol remains preferred for Deep, Exhaustive, and
  future Strategy Research. Phase 2 does not implement automatic routing.
- **Context and cost:** retain native Responses context management and opaque
  native-compaction replay. Do not reintroduce historical File Search result
  payload replay.
- **Source integrity:** raw Jacob transcripts remain factual authority.
  Substantive Direct source teaching needs native support; cited sources and
  retrieved passages remain distinct; exact timestamps remain verifiable.

## Future UX note

For exact-source questions, a later phase may highlight the matching timestamp
range inside a long retrieved passage. This is a non-blocking UX improvement and
is not implemented by this acceptance closure.

## Boundary of this acceptance

Phase 2 passed its foundation acceptance; it does not authorize Phase 3,
automatic model routing, or merging this feature branch to main. The existing
technical hardening records remain relevant implementation history.
