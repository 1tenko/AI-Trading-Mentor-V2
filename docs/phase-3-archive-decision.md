# Architecture Decision: Archive Phase 3 Assimilation

**Decision date:** 2026-08-25
**Status:** Accepted product decision

## Decision

Phase 3 was implemented as an isolated six-source assimilation experiment on
`feature/phase-3-knowledge-assimilation`, ending at
`6c5772eb414b68c6baca205a44c59ed334dbcb83`. Preserve that branch and its
history as an experimental record; do not merge or cherry-pick its compiler,
derived-store, orientation, pilot, or accounting runtime into the continuing
product.

The six-source compiler worked technically. Phase 3B then compared lean
derived orientation with GPT-5.6 Sol plus the same scoped raw File Search.
Sol's dynamic raw-source synthesis was sufficiently strong for the intended
trading-research-supervisor work. Assimilation added context, cost, and latency
without enough product benefit to justify full-corpus operation.

Full-corpus assimilation is therefore abandoned. Raw source material remains
the factual authority, and Sol continues to perform source synthesis dynamically
at query/research time with native citations for Direct source teaching.

## Consequence

Continuing product phases branch from the accepted Phase 2 closure
`f809193ef2749dbe53c0af14e5d3196420c896f9`. Phase 4 is Trader Profile /
Editable Memory. This decision retains the Phase 3 evidence and provenance
lessons, but not its runtime complexity or private pilot artifacts.
